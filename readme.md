# 🚧 Түр Зогсолтын Мэдэгдэл

## ⚠️ Хүндэт хэрэглэгч танд

Энэхүү вэбсайтад **түр хугацааны техникийн доголдол** үүссэн тул одоогоор хэвийн ажиллахгүй байна.

🙏 **Учирсан хүндрэлд чин сэтгэлээсээ хүлцэл өчье.**

Манай баг асуудлыг аль болох хурдан шийдвэрлэхээр ажиллаж байгаа бөгөөд үйлчилгээ тун удахгүй хэвийн болно.

⏳ **Та хэдхэн минут хүлээгээд дахин оролдоно уу.**

Таны тэвчээр, ойлголцол болон үргэлж дэмждэгт баярлалаа. ❤️
