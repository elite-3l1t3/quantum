Нууцлалын бодлого

Сүүлд шинэчилсэн: 2026-10-22

1. Бидний цуглуулдаг мэдээлэл

  • Discord-оор нэвтрэхэд: Discord ID, username, нэр, avatar. Имэйл хаягийг ашиглахгүй. Discord ID нь зөвхөн танд болон админд харагдана.
  • Таны оруулсан: username, нэр, bio, байршил, линк, өнгө, зураг, видео, дуу.
  • Идэвхи: профайл тус бүрийн view (үзэлт) тоо, like. View-г давхардуулахгүйн тулд хөтөч дээрх санамсаргүй ID-г (нэр, IP-гүй) хадгална.

2. Нийтэд харагдах зүйл

Release болсон профайлын username, нэр, bio, байршил, линк, avatar, background, дуу, видео, #bId, badge, view болон like-ийн тоо нийтэд харагдана. Дуу, видео, зургийг хэн ч татаж авч болно гэдгийг анхаараарай.

3. Хэрхэн ашиглах

Мэдээллийг зөвхөн сайтыг ажиллуулах, профайл харуулах, админы удирдлага (ban, username өөрчлөх, waitlist release) хийхэд ашиглана. Бид мэдээллийг зарахгүй, зар сурталчилгаанд ашиглахгүй.

4. Хадгалалт ба гуравдагч тал

Мэдээлэл Supabase дээр хадгалагдах ба сайт GitHub Pages дээр байрлана. Discord нь нэвтрэлтийг гүйцэтгэнэ. Профайл дээр байрлуулсан линк, Google Fonts болон jsDelivr зэрэг гадаад үйлчилгээ нь таны IP хаягийг өөрийн нөхцөлөөр харж болно.

5. Хөтөчид хадгалагдах зүйл

Нэвтрэлтийн session, хүлээгдэж буй username болон view-н ID-г хөтчийн localStorage-д хадгална. Сурталчилгааны cookie ашиглахгүй.

6. Хадгалах хугацаа ба устгах

Мэдээллийг бүртгэл идэвхтэй байх хугацаанд хадгална. Бүртгэл болон оруулсан файлаа устгуулахыг хүсвэл админд хандана. Ban хийгдсэн бүртгэлийн Discord ID-г дүрэм зөрчсөн хүн дахин бүртгүүлэхээс сэргийлж хадгалж болно.

7. Хүүхэд

Discord-ын насны шаардлагыг хангаагүй хүн biof-ийг ашиглахгүй. Хүүхдийн хувийн мэдээллийг зориуд цуглуулахгүй.

8. Өөрчлөлт ба холбоо барих

Бодлогыг шинэчилж болно. Асуулт, хүсэлтийг Discord-оор сайтын админд (#1) илгээнэ үү.
